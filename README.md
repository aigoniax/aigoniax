<h2> About me</h2>

I'm a 4th-year BSIT student at CIT-U. Most of what I've built so far comes from academic and personal projects, mainly web applications using Spring Boot, Django, and React, plus some front-end and mobile work. I like software that works well and looks clean, and I try to leave behind code and documentation that other people can actually follow.

In group projects I'm usually the one who ends up leading: breaking the work into tasks, checking on progress, keeping communication going, and making sure we get from planning to a working build. I enjoy that side of development as much as the coding, and I'm still learning to get better at both.

## Selected projects

### 🗂️ [OpenCodeHub](https://github.com/aigoniax/CSIT327-G8-OPENCODEHUB)

`Django` `PostgreSQL (Supabase)` `HTML/CSS/JS`

A web platform for managing and sharing projects. Users can create projects, upload files, set projects as public or private, share them by link, and leave comments. Built by a seven-member team for CSIT327, where I was the lead full-stack developer.

🔗 [Live demo](https://csit327-g8-opencodehub-mciy.onrender.com/)

### 🌾 AgriBridge

`React` `Spring Boot` `PostgreSQL (Supabase)`

A marketplace that connects farmers directly with buyers. Farmers post product listings, buyers place orders, and the two sides can message each other about an order. It has separate farmer, buyer, and admin dashboards, JWT-based login, and admin approval for farmer accounts.

🔗 [Web app](https://github.com/aigoniax/AGRIBRIDGE-WEBAPP) · [Backend API](https://github.com/aigoniax/AGRIBRIDGE-BACKEND)

### 🔢 [Number System Converter](https://github.com/aigoniax/IGONIA-NUMBER-SYSTEM)

`HTML` `CSS` `JavaScript`

One of my first projects: a browser-based converter between binary, octal, decimal, and hexadecimal, made for an early programming course.
